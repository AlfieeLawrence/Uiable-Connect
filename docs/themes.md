# Themes

Open **Settings** in the app.

## App theme

Colours the whole UI. Options include:

- Dark (default)  
- Light  
- Solarized  
- Dracula  
- Monokai  
- System (follows the OS light/dark preference when selected)

The choice is stored on **this device** (`localStorage`).

## Terminal theme

Separately select a terminal palette. Changing the **app** theme also matches the terminal when a corresponding palette exists; you can still override the terminal afterwards.

## Wallpaper / chrome

Dark builds use a deep background (mobile Capacitor splash/background aligns with the dark chrome). If an older iOS build showed only a blank black screen after launch, update to **1.4.3+**.
